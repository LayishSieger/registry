# Security Policy

## Supported versions

This is a public [shadcn](https://ui.shadcn.com) component registry. Security fixes, when needed, are applied on the default branch (`main`).

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security reports.

Prefer one of these paths:

1. **GitHub private vulnerability reporting** (preferred once enabled): use **Security → Report a vulnerability** on this repository.
2. Contact the maintainer via their GitHub profile: [@LayishSieger](https://github.com/LayishSieger).

Include enough detail to reproduce the issue (affected paths, steps, impact). You should receive an acknowledgment when the report is seen; remediation timing depends on severity and scope.
